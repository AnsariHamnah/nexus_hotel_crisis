# NEXUS — Hotel Crisis Intelligence Network

Google Solution Challenge 2026

NEXUS transforms existing hotel infrastructure into a crisis intelligence network.

## Core Features

- Silent SOS using landline dial 00 twice
- Silent SOS using keycard tap 3x
- Firebase real-time alert system
- Gemini AI crisis triage
- Staff Flutter app
- React control room dashboard
- IPTV evacuation broadcast
- Offline edge node using Raspberry Pi + MQTT

## Tech Stack

- Firebase
- Gemini API
- Flutter
- React + TypeScript
- Node.js
- MQTT
- Google Maps Platform
